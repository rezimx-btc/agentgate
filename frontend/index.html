How it works

  1. Connect your wallet on BNB Chain.
  2. The page reads balanceOf(yourAddress) on the Agent ID registry. If it is > 0, you hold an Agent ID.
  3. Click Mint. Your wallet asks you to confirm — the transaction only calls mint() on the AgentGate contract. No BNB is sent to the contract; you pay only network gas.
  4. One mint per address. If you already minted, the button stays disabled.

No login, no QR code, no session stored anywhere. This page is static — there is no backend server. It never asks for a seed phrase, private key, or pairing code. Never enter those anywhere.
